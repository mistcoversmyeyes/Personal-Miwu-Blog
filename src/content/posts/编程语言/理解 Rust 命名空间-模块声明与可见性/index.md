## 阅读 mod.rs 时产生的疑问

在阅读 DragonOS 的 `kernel/src/filesystem/mod.rs` 时，我开始关注一个问题：函数名、结构体名和模块名都属于标识符，Rust 如何组织这些名字，又如何限制它们能在哪里被使用？

我最初把 `mod` 联想到 C++ 的 `namespace`，把 `pub(...)` 联想到名字的可见性。顺着这些声明继续读，我尝试用一个算子模型描述自己的理解：

```text
ID 可见性 = scope_ops(pub 关键字所在的位置)
```

本文准备沿着这段理解过程，区分名字的组织方式、声明的可见性，以及从某个位置访问它时需要满足的条件。
